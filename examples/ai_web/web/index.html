AI Logic

Ask a Gemini model through Firebase AI Logic with firebase_ai_dart (pure Dart, compiled to WebAssembly or JavaScript) and watch the answer stream in.

Nothing is stored, and nothing leaves the browser except to firebasevertexai.googleapis.com (the page's Content-Security-Policy allows no other host). Your API key, app id and project id are not stored. The API key of a web app is public: turn on App Check enforcement for AI Logic in your project, and restrict the key to your site and to the Firebase AI Logic API. Every prompt is billed to your project.
