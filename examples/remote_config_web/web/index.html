Remote Config

Fetch and activate the Remote Config values of your project with firebase_remote_config_dart (pure Dart, compiled to WebAssembly or JavaScript), and watch realtime updates arrive. The installation is stored in this browser's IndexedDB.

Nothing is stored except the installation record (an id and its tokens) in IndexedDB, and nothing leaves the browser except to firebaseinstallations.googleapis.com, firebaseremoteconfig.googleapis.com and firebaseremoteconfigrealtime.googleapis.com (the page's Content-Security-Policy allows no other host). Your API key, app id and project id are not stored. The values of a Remote Config template are public: do not keep secrets in it.
