Realtime Database playground

Try firebase_database_dart, the pure-Dart Realtime Database client. Compiled with dart2wasm.

Simulated server: rules are not evaluated; this is not the real backend. The client is the real one. The server is a small program in this page that answers it from its own data. The page can connect to nothing but the host that serves it, and everything is gone when you reload.
