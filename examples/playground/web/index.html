Firestore playground

Try cloud_firestore_dart, the pure-Dart Cloud Firestore client, and watch what it does. Compiled with dart2js.

Local cache only. The client runs with its network disabled, on a memory cache. Nothing you type leaves this browser, and everything is gone when you close or reload the tab.

    Writes waiting for a server 
    
      
    Each write is applied to the cache at once, so the listener sees it, and then
        waits for the backend to confirm it. There is no backend here, so every write stays in this
        queue and its Future never completes. An app that is offline sees exactly this; with
        a connection the queue empties as the server answers.
