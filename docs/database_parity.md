# Realtime Database parity with the JS, Android, iOS and C++ SDKs

This document compares the public API and the behaviour of the Firebase Realtime Database client in four official SDKs with
`firebase_database_dart` (`firebase_database/firebase_database_dart`), feature by feature:

- **JS**: `packages/database` and `packages/database-compat` of firebase-js-sdk at `a086865`. It is the reference for the
  protocol and for behaviour.
- **Android**: `firebase-database` of firebase-android-sdk at `2cfdd03`.
- **iOS**: `FirebaseDatabase` of firebase-ios-sdk at `cef246f`.
- **C++**: `database` of firebase-cpp-sdk at `09d2e7a` (the desktop code speaks the protocol itself; the mobile wrappers
  delegate to the native SDKs).
- **Dart**: `firebase_database_dart` as it is in the code of this repository.

The four SDKs were read as clones on 2026-11-22, from GitHub only; their code was read, not run. The Dart column was
audited again on 2026-11-28 against the code of `main`, with a file and line and the test for every built row. Line
numbers will drift.

Path shorthand: `J:` is JS `packages/database/src/`, `JC:` `packages/database-compat/src/api/`, `JT:` and `JCT:` their
`test/` folders; `A:` is Android `firebase-database/src/main/java/com/google/firebase/database/`; `I:` is iOS
`FirebaseDatabase/Sources/` and `IH:` its public headers; `Ci:` is the C++ public API `database/src/include/firebase/`,
`Cd:` its desktop implementation `database/src/desktop/` and `CT:` `database/tests/desktop/`. A "—" means the SDK has
no such feature; "partly" means it has it with a missing piece or in a weaker form.
