# Upstream analysis, chunk 2 (142 commits, 2022-01-11 to 2023-02-06)

Dart baseline for comparison: cloud_firestore_vm lib/src/firebase/firestore (SQLite schema version 8, 2019 protos, no overlays, no client-side index engine, no OR / NOT_IN / aggregation / App Check). Android SQLite schema was version 16 at the start of this chunk's schema work (VERSION 15 -> 16 in f25efea). Releases covered by this chunk (from android_firestore_changelog.md): 24.0.2 (Jan-Feb 2022) through 24.4.4/24.4.5 (Jan-Feb 2023).

## 1. Summary of themes

1. About 60 of the 142 commits are the **client-side index engine and overlays** (FieldIndex, IndexManager, IndexBackfiller, SQLiteIndexManager, DocumentOverlayCache, TargetIndexMatcher, descending/inequality index scans, schema 16). Beta in 24.1.0 and not user-visible unless setIndexConfiguration is called. The Dart port has none of it; the unrelated 2019 collection-index code (local/sqlite/sqlite_index_manager.dart) is a different design. Treat as one big optional epic, not as a list of fixes.
2. **OR queries foundation** (CompositeFilter, DNF, IN expansion, serializer, OR served from the index): about 20 commits, internal only here; the public Filter.or/and API appears in a later chunk (unverified), released as 24.4.5.
3. **COUNT aggregation** (a50da9f, 42c8d72, f2e4bd0, ab87571): the only new remote RPC in the chunk (RunAggregationQuery). Public as Query.count() in 24.4.0. Needs a proto regeneration, which the Dart proto set (2019) does not contain.
4. **Transport / headers**: new x-goog-request-params routing header (624be9c); BatchGetDocuments logical termination (b564bee); App Check stream re-establishment added then reverted within the chunk (26d0992 / 62d868a); shutdown deadlock fix (Android-only).
5. **Transactions**: TransactionOptions (maxAttempts, 24.2.0) and a correctness fix for writes to documents read as missing (24.4.1).
6. **Listener correctness**: initial snapshot from an empty local cache (hasCachedResults, 24.4.1) and "send query to backend before local processing" latency change (24.0.2).
7. **Overlay bug-fix series** (about 12 commits: multi-batch, offline, multiple patches, patch optimization): irrelevant until overlays are ported; they are real data-correctness fixes if they are.
8. **Perf/memory**: remote document reads elision, apply query check sooner (24.4.3), parse overlays in the background.
9. The rest is build/version churn (gradle, gRPC bumps, Robolectric, Kotlin, ktfmt), tests, changelog, Android-specific lint/executors.
10. Wire/protocol compatibility: no change to the Listen/Write stream protocol, existence-filter handling or backoff happened in this chunk (BloomFilter / ExistenceFilter v2 exist in the clone at HEAD but come in later chunks: unverified). The wire-relevant items here are the extra routing header, the updated protos (OR operator, aggregation, int64 up_to) and logical termination for BatchGetDocuments.

Counts by relevance: MUST 4, SHOULD 8, COULD 38, N/A 92.

## 4. Dependencies and ordering

- **COUNT**: f5ac43c (protos, includes OR operator) and 42c8d72 (int64 up_to) first, then a50da9f (plumbing: Query.count, SyncEngine/RemoteStore/Datastore.runCountQuery), then f2e4bd0 (public API shape: long getCount, equals/hashCode). ab87571 and 50fae3c are tests that need backend support. Later chunks probably add sum/average and AggregateSource changes (unverified; changelog 24.9.1).
- **OR queries**: 514402d (CompositeFilter) -> 53ff022 (serializer) -> 7fb9889 (operator enum) -> 79847b9 (DNF) -> 9a80448 (IN expansion) -> 310ce36 -> 5894117, 21d351e, a283019, 737ff58, 07dec7a (follow-ups/cleanups); 69104c7 and 943abd8 serve OR from the index and need the index epic. f5ac43c supplies the proto OR operator. The public Filter.or/and API is not in this chunk (unverified which chunk). Dart's core/filter/ and remote_serializer.dart would change together.
- **Index/overlay epic** (all depend on one another and on schema 16): 20fe010 -> 275b3eb -> 96a4b39 -> 2715647 -> f25efea (flag removal, VERSION 16) -> a26c34c, 6e96da6, 54f6ee7, 17661dc, d8ec3fb, 2cb5492 (public setIndexConfiguration). Overlay fixes 9b2c2d3, df21954, 4d49364, 18fa5f3, 7926a0a belong with it. The Dart schema is at version 8, so even the schema versions 9-15 from earlier chunks are missing; do not port individual commits from this group in isolation.
- **App Check**: 26d0992 is reverted by 62d868a (same chunk); treat as no change. The original integration (ff414cb2c, Oct 2021) is in an earlier chunk.
- **Listener fix**: 6498bd0 touches QueryListener, View, ViewSnapshot, SyncEngine and TargetChange together (createSynthesizedTargetChangeForCurrentChange(isCurrent, resumeToken)); port as one unit.
- **Transactions**: a0fcca1 (Precondition.exists(false) and retryable ALREADY_EXISTS) is independent of 672c6dc (TransactionOptions); both touch core/sync_engine.dart and core/transaction.dart.
- **Supersession across chunks**: 88ea99b (readTime) continues earlier readTime/overlay commits (not read: unverified); 624be9c's header value may be altered by a later commit (unverified). fea70f7 reverts ffc5d33 within the chunk.
