# firebase_storage_dart

Unofficial, pure-Dart client of [Cloud Storage for Firebase](https://firebase.google.com/docs/storage) for
Dart servers, command line tools and Flutter apps, on top of
[`firebase_app_dart`](https://pub.dev/packages/firebase_app_dart). It is not affiliated with or supported by
Google or Firebase.

> **Status: 0.1.0, unreleased.** The documentation is still being written.
